## 共同写作与交付要求

以下为可调整的编辑默认值，适用于各平台的论文解读稿；以作者当前修改、明确模板和栏目要求为准。VALSE 分享提案按讲解需要选取图表，长文分析可放附录。

- **标题与开头：** 突出研究问题、关键设计与具体价值。团队或机构信息须核实，结果带比较条件；可以用有解释作用的比喻，不为吸引阅读添加无依据的排名。尊重已审定标题，不机械替换为统一句式。
- **论文信息：** 题名、作者、单位和发表状态核对原论文。可在资源卡附近加入原论文题名、作者与机构截图；不能沿用别篇论文的署名。
- **图文衔接：** 先解释问题，再用引导句带出概念对比图；先说明角色、模块或输入输出，再展示详细流程图。每张图回答所在段落的问题，避免紧接资源列表突然插入尚未介绍的框架。
- **实验证据：** 主结果与关键消融优先采用原论文清晰截图，保留表头、指标、重要脚注和比较条件。图后立即解释关键结果、取舍与适用范围；不要求每张表都出现，不裁掉不利结果。作者要求可编辑表格时忠实重建并核对数值。
- **图注与资源：** 图注简短概括内容，默认不自动编号，不加重复来源套话；来源、原图号和裁剪信息单独记录，必要署名仍保留。文章正文展示完整可见网址；README 和参考指南可使用正常 Markdown 超链接。
- **Word 与修订：** 正文可编辑，图片清晰，图注与图同页。渲染并检查全部页面。最新人工修改稿是下一轮依据；旧 Markdown 必须随最终稿更新，不能反向覆盖作者修改。
- **对外文字：** 投稿信只说明研究选题、稿件和附件。“稿件 Word 版本随信附上。”是默认附件说明；审核状态、批准记录、模型自检和写作依据放独立工作记录，不混入推文或邮件。

## 每次任务的样文校准

优先读取用户提供的同栏目参考文；否则寻找所选公众号同栏目、相近主题的一至三篇可读全文。新闻快讯和作者技术解读应分别对待。近期样文优先，只有历史样文时标明日期。搜索摘要、登录页和仅有标题的结果不能当作已经阅读全文。

在任务目录写 `style-profile.md`，用下列维度记录来源观察和本稿落实方式：

| 维度 | 需要比较的内容 |
| --- | --- |
| 标题 | 问题式或结论式、成果信息密度、是否带论文/机构信息；无录用证据不套会议前缀 |
| 导语 | 从读者场景、研究缺口还是结果切入，何时交代方法与资源 |
| 节奏 | 短段与长段比例、小标题密度、术语解释位置 |
| 技术深度 | 模块、训练、公式、消融如何展开，保留哪些复现条件 |
| 图表 | 方法图与结果表的先后、图注怎样配合解释 |
| 结尾 | 总结研究启发、边界、资源与团队信息的方式 |

标明状态：`sample_calibrated`（读到近期、相关、来源直接的全文并据此调整）、`limited_reference`（已读参考为作者审定稿、历史样文、署名同步、转载或其他间接依据）、`suggested_format`（未取得可靠全文，按平台建议结构写作）。同时记录来源归属、原文/转载/编辑日期、访问日期及栏目范围，状态不是相似度评分。微信原版未读到时不能声称已复现其版式。不要编造相似度百分比或声称是编辑部模板。没有可读样文仍完成 Word 草稿，将限制放在独立备注，不混进文章正文。

样文去重时核对来源与编辑署名：相同稿件跨平台转载只算一个原创来源，可分别证明转载选择，不能算两套独立的品牌写法。网站页脚、推荐栏和抓取时间不能当原文发布日期；动态壳和搜索摘要不能登记为已读全文。渠道核验与风格依据分别记录，风格已校准不代表地址可投递。

完成稿件后逐项对照该档案，写明六个维度在本稿的位置和实现方式，偏离处注明原因。不满足则修订后再交付；只替换媒体名不算适配，不能照搬样文表达、媒体署名或品牌标识。这里是模型编辑检查，不替代用户对最终 Word 的人工审核或发送确认。
