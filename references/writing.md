# 平台写作档案

以下篇幅和结构为编辑建议，不是官方强制模板。收到用户模板或当期投稿须知时以其为准。

| 平台 | 建议篇幅（中文字） | 结构与侧重点 |
| --- | --- | --- |
| 机器之心 | 1800–2800 | 技术问题与亮点导语 → 论文资源卡 → 方法图解 → 实验 → 局限和启发；写清机制，录用信息须核实。 |
| 量子位 | 1200–2000 | 熟悉场景 → 一句话成果 → 两三处关键解释 → 结果 → 团队与链接；短段落，解释术语，克制夸张。 |
| 新智元 | 1500–2400 | 引人关注的问题 → 研究进展与例子 → 原理 → 应用意义及边界 → 链接；不编行业反应。 |
| CVer | 1800–3000 | 任务与论文信息 → 贡献 → 框架/模块 → 实验/消融 → 代码；面向 CV 读者，保留技术细节。 |
| 极市平台 | 1800–3000 | 技术难点 → 方案 → 训练/推理 → 评测 → 复现条件；复现命令核实，未测不称跑通。 |
| 我爱计算机视觉 | 1600–2600 | 问题与直觉 → 论文信息 → 方法图解 → 定量/定性结果 → 点评与链接。 |
| PaperWeekly | 2200–3500 | 导读 → 背景 → 方法 → 实验/消融 → 局限讨论 → 资源；强调研究逻辑，保留必要公式。 |
| VALSE | 1200–2200 | 客观摘要 → 问题贡献 → 方法证据 → 资源 → 团队；学术风格，活动邮箱不等于投稿邮箱。 |

## 有来源的规则

- 机器之心：[AIxiv 历史官方文章](https://www.jiqizhixin.com/articles/2025-02-19-3) 公开投稿邮箱；可参考背景、方法、贡献、实验、作者介绍的结构。不照抄套话或媒体署名。
- 量子位：[官方联系页](https://www.qbitai.com/联系我们) 要求主题标注“投稿”或“爆料”。[2023 投稿须知转载](https://www.10100.com/article/3026841) 提到 2000 字内 Word 稿、开头“XXX 投稿”和项目链接；属二手历史信息，使用前复核，署名由用户提供。
- PaperWeekly：[2026 署名 PaperWeekly 的文末说明](https://deepseek.csdn.net/6a28de5610ee7a33f27a0f7e.html) 建议 Markdown、配图单独附件、即时联系方式、说明已发表或待发表情况。来源托管在第三方，不称当前官网规则，不沿用早期稿费承诺。
- 其余平台尚无可靠统一格式要求。使用建议格式，并说明格式及渠道核验状态。

投稿信简述研究问题、贡献、带条件结果和选题适配性，附资源及附件说明。首发、其他投稿和身份只写用户确认的信息。咨询信只询问是否接收这一研究方向和正确投稿途径，默认不附全文。不承诺录用、处理时间或稿费。
