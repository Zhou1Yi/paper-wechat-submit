## 每次任务的样文校准

优先读取用户提供的同栏目参考文；否则寻找所选公众号同栏目、相近主题的一至三篇可读全文。新闻快讯和作者技术解读应分别对待。近期样文优先，只有历史样文时标明日期。搜索摘要、登录页和仅有标题的结果不能当作已经阅读全文。

在任务目录写 `style-profile.md`，用下列维度记录来源观察和本稿落实方式：

| 维度 | 需要比较的内容 |
| --- | --- |
| 标题 | 问题式或结论式、成果信息密度、是否带论文/机构信息；无录用证据不套会议前缀 |
| 导语 | 从读者场景、研究缺口还是结果切入，何时交代方法与资源 |
| 节奏 | 短段与长段比例、小标题密度、术语解释位置 |
| 技术深度 | 模块、训练、公式、消融如何展开，保留哪些复现条件 |
| 图表 | 方法图与结果表的先后、图注怎样配合解释 |
| 结尾 | 总结研究启发、边界、资源与团队信息的方式 |

标明状态：`sample_calibrated`（读到近期、相关、来源直接的全文并据此调整）、`limited_reference`（已读样文为历史、署名同步、转载或其他间接依据）、`suggested_format`（未取得可靠全文，按平台建议结构写作）。同时记录来源归属、原文/转载/编辑日期、访问日期及栏目范围，状态不是相似度评分。微信原版未读到时不能声称已复现其版式。不要编造相似度百分比或声称是编辑部模板。没有可读样文仍完成 Word 草稿，将限制放在独立备注，不混进文章正文。

样文去重时核对来源与编辑署名：相同稿件跨平台转载只算一个原创来源，可分别证明转载选择，不能算两套独立的品牌写法。网站页脚、推荐栏和抓取时间不能当原文发布日期；动态壳和搜索摘要不能登记为已读全文。渠道核验与风格依据分别记录，风格已校准不代表地址可投递。

完成稿件后逐项对照该档案，写明六个维度在本稿的位置和实现方式，偏离处注明原因。不满足则修订后再交付；只替换媒体名不算适配，不能照搬样文表达、媒体署名或品牌标识。这里是模型编辑检查，不替代用户对最终 Word 的人工审核或发送确认。
