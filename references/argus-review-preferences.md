# ARGUS 示例的用户审稿偏好

依据：用户提供的《论文公众号宣发批注意见.docx》，五条正文意见及四张示例图。只记录与稿件修订相关的要求；文档中的示例论文作者和机构不属于 ARGUS，不能抄入本稿。

- 标题应突出读者关心的问题或论文贡献，使用“多智能体”，不以具体智能体数量作为标题亮点。模型实际角色分工仍须在方法说明中准确表达。
- 加入 ARGUS 论文题名、作者与机构的原始截图，置于论文资源信息附近；检查截图确属本论文。
- 公众号正文直接显示完整网址，不只显示“项目主页”“代码”等隐藏目标的超链接文字。Word 导出后检查不存在被隐藏的网址；该偏好不禁止 README 的正常 Markdown 链接。
- 图注简短说明内容，不加“图片来自项目主页”等重复来源套话，不自动加图序号。裁剪可以去除空白和原表题，但不能删掉指标名、比较条件、重要脚注或改变数值；来源、原表号与裁剪区域另存记录。
- 主实验和关键消融使用原论文表格截图，紧接解释结果及比较条件；不重建可编辑表格。正文仍为可编辑文字。

这些是 ARGUS 示例的编辑要求，不是其他作者、全部稿件或各平台编辑部的通用规则。邮件收件人和附件仍需用户对最终版本明确确认；收到修改意见或称赞稿件不是发送许可。
