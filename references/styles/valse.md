## 写作落实

| 维度 | 本稿采用的做法 |
| --- | --- |
| 标题 | 客观论文主题；提案不冒充已排期的“第 N 期”。 |
| 导语 | 用短研究介绍说明问题、方法、证据；明确提案身份。 |
| 节奏 | 资源与元信息清楚，视频讲解提纲分段；不硬套新闻导语。 |
| 技术深度 | 短介绍概括贡献，扩展解读作为可选 Word 附录。 |
| 图表 | 方法概览服务讲解；有作者视频时引用真实视频链接。 |
| 结尾 | 已确认的讲者信息、论文代码；不虚构组织者致谢。 |

默认生成可编辑 Word“研究分享提案”：简短研究介绍 + 讲解提纲 + 资源 + 独立作者待确认事项。若用户仍要长篇推文，完整解读附在 Word 中，并注明属于建议材料，不称已对齐论文速览正式发布格式。没有官方要求时不硬设时长或正文长度。

## ARGUS 原创适配示例

**标题：** ARGUS：面向 AI 生成视频检测的多智能体框架——研究分享提案

**短介绍：** ARGUS 探索多智能体分工在 AI 生成视频检测中的应用。系统将独立观察与最终判断分离，由四个观察智能体提供证据，裁判综合判断；训练流程包括监督微调与 GRPO。分享拟介绍框架设计、数据构成和面向未见生成器的评测，并讨论结果的适用边界。

**讲解提纲：** ① 问题与研究动机；② 观察者—裁判分工；③ 训练与数据；④ OOD 评测和结果；⑤ 局限与开放问题。

**资源与备注：** 列论文和项目地址；英文摘要如需加入，应准确沿用作者自己的论文内容。ARGUS 的当前核对版本为 arXiv 预印本，未确认顶会顶刊录用，也未提供讲者、视频和栏目接收资格。这些放在独立作者备注，不编成已完成事项。
