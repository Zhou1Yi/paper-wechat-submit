## 写作落实

| 维度 | 建议写法 |
| --- | --- |
| 标题 | 客观论文主题；提案不冒充已排期的“第 N 期”。 |
| 导语 | 用短研究介绍说明问题、方法、证据；明确提案身份。 |
| 节奏 | 资源与元信息清楚，视频讲解提纲分段；不硬套新闻导语。 |
| 技术深度 | 短介绍概括贡献，扩展解读作为可选 Word 附录。 |
| 图表 | 方法概览服务讲解；有作者视频时引用真实视频链接。 |
| 结尾 | 已确认的讲者信息、论文代码；不虚构组织者致谢。 |

默认生成可编辑 Word“研究分享提案”：简短研究介绍 + 讲解提纲 + 资源 + 独立作者待确认事项。若用户仍要长篇推文，完整解读附在 Word 中，并注明属于建议材料，不称已对齐论文速览正式发布格式。没有官方要求时不硬设时长或正文长度。

## 结构与图文安排

题名与作者单位 → 简短研究介绍 → 讲解提纲 → 论文、代码及已有视频 → 已确认的讲者资料。

研究分享提案可用题名、作者与机构截图辅助核对，方法概览跟随讲解提纲。主结果与消融截图按讲解需要选取，较长的技术分析放扩展解读；不强行把视频栏目改成长篇媒体稿。

遵循[共同写作与交付要求](../writing.md#共同写作与交付要求)：资源网址可见、图注简短、图片有上下文，最终 Word 交给投稿者审核。结构可按论文贡献和当前栏目要求调整。
