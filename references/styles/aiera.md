## 写作落实

| 维度 | 本稿采用的做法 |
| --- | --- |
| 标题 | 具体场景或研究矛盾，加方法信息；不制造行业震动。 |
| 导语 | 独立“导读”浓缩问题、方案、意义，随后交代论文资源。 |
| 节奏 | 场景叙述连接问题式小标题，每节回答一个问题。 |
| 技术深度 | 先解释为什么需要这个设计，再讲关键模块和必要训练。 |
| 图表 | 场景或挑战图 → 方法图 → 实验证据，图注说明读图重点。 |
| 结尾 | 有条件的研究意义与局限；作者资料仅用已确认内容。 |

建议 1500–2600 中文字，依据方法复杂度调整。导读只写“导读”，不冒用“新智元报道”、编辑署名或品牌身份。

## ARGUS 原创适配示例

**标题：** AI 视频鉴伪如何给出依据？ARGUS 让观察者与裁判分工

**导读：** 一段视频被判定为生成内容后，支撑结论的证据同样值得追问。ARGUS 将这一任务拆成两个环节：四个智能体独立观察，裁判汇总证据后判断。研究围绕这种分工构建训练流程，并在包含未见生成器的测试设置中评估其表现。

**正文大纲：** ① 看起来合理的视频，怎样寻找鉴伪线索？② 为什么不让观察者直接下结论？③ 裁判如何学习综合证据？④ 实验支持了哪些结论？⑤ 离真实使用还有哪些问题？

**图表安排：** 任务示例 → 观察与裁判流程图 → 结果表。把训练细节集中到第三节，避免在导读堆术语。局限来自论文，不从应用设想推出已经部署。
