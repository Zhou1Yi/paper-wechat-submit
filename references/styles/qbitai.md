## 写作落实

| 维度 | 建议写法 |
| --- | --- |
| 标题 | 一项具体问题或带条件结果，加方法名；有证据才写会议或机构。 |
| 导语 | 用读者能理解的失败场景开头，尽早交代解决思路。 |
| 节奏 | 短段落、问题式小标题；首次出现术语时解释。 |
| 技术深度 | 保留决定贡献的训练与消融；不把量子位一概写成轻量快讯。 |
| 图表 | 先给直觉示意，再讲机制和结果；数字后说明比较对象。 |
| 结尾 | 研究意义与边界，再集中列论文、代码、数据入口。 |
